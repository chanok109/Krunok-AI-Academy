# วิธีนำเว็บ KruNok AI Academy ขึ้น Server โรงเรียน

## ไฟล์ที่ต้องอัปโหลด
ใช้ไฟล์ `release/KruNok-AI-Academy-school-upload.zip` (หรือโฟลเดอร์ `dist/`) ทั้งหมด

## ขั้นตอน
1. แตกไฟล์ zip แล้วอัปโหลด **เนื้อหาในโฟลเดอร์** (`index.html`, `assets/`, `models/`, `samples/`, `.htaccess`, `web.config`) ไปที่โฟลเดอร์เว็บของ server เช่น `public_html/` หรือ `public_html/ai/`
2. เปิด `https://โดเมนโรงเรียน/` (หรือ `/ai/`) ก็ใช้งานได้ทันที ไม่ต้องตั้งค่าเพิ่ม

## ทำไมใช้ได้ทุกโฟลเดอร์
- ตั้ง `base: './'` ใช้ path แบบ relative ทั้งหมด จึงวางในโฟลเดอร์ย่อยได้
- ใช้ลิงก์แบบ `#` (hash) ไม่ต้องตั้ง rewrite ของ server
- `.htaccess` (Apache) และ `web.config` (IIS) ตั้ง MIME ของ `.wasm`/`.json` ให้แล้ว (ใช้กับ Lab 2.5 ตรวจจับวัตถุ)

## ข้อควรระวัง
- ห้ามเปิด `index.html` ด้วยการดับเบิลคลิก (file://) เพราะเบราว์เซอร์บล็อกสคริปต์ module ต้องเปิดผ่าน server เท่านั้น
- ต้องมีอินเทอร์เน็ตเพื่อโหลดฟอนต์ Google Fonts (ถ้าไม่มี จะใช้ฟอนต์สำรองของเครื่อง)
- ความก้าวหน้าของนักเรียนเก็บในเบราว์เซอร์เครื่องนั้น ๆ (localStorage)

## อัปเดตเวอร์ชันใหม่
```
npm run build
```
แล้วอัปโหลดเนื้อหาใน `dist/` ทับของเดิม
