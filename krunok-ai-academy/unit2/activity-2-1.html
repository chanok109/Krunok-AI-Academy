กิจกรรมที่ 2.1 นักสำรวจภาพ

ค้นหาคอมพิวเตอร์วิทัศน์ในชีวิตจริง แล้วเขียนโปรแกรมสำรวจตัวเลขในภาพของตนเองด้วย OpenCV

แผนงาน

  • 5 นาทีนาทีที่ 0–5อ่านภารกิจ และเตรียมภาพ
  • 10 นาทีนาทีที่ 5–15ตอนที่ 1 วิเคราะห์ระบบใกล้ตัว
  • 25 นาทีนาทีที่ 15–40ตอนที่ 2 เขียนและทดสอบโปรแกรม
  • 10 นาทีนาทีที่ 40–50ตอนที่ 3 สะท้อนคิด ตรวจงาน และส่งงาน

สิ่งที่กรอกเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ครูจะไม่เห็นจนกว่านักเรียนจะส่งงาน

งานเดี่ยว: ปรึกษาเพื่อนได้ แต่นักเรียนแต่ละคนต้องเขียนโปรแกรมและตอบคำถามด้วยตนเอง

ระวัง: ใช้ภาพของตนเองหรือภาพบรรยากาศ ถ้าภาพมีเพื่อนอยู่ด้วย ต้องขอความยินยอมก่อน

ตอนที่ 1 คอมพิวเตอร์วิทัศน์ใกล้ตัว

เลือกระบบจริงที่นักเรียนพบในชีวิตประจำวัน 1 ระบบ เช่น ปลดล็อกด้วยใบหน้า สแกน QR Code หรือแอปแปลภาษาจากภาพ แล้วตอบคำถามต่อไปนี้

ตอนที่ 2 โปรแกรมนักสำรวจภาพ

เป้าหมายเขียนโปรแกรมที่อ่านภาพของตนเอง บอกขนาดภาพและค่าสีของพิกเซลกึ่งกลาง แสดงภาพสีกับภาพเทา แล้วบันทึกภาพเทาเป็นไฟล์ใหม่ ทำตามลำดับด้านล่าง

  1. เตรียมภาพเลือกภาพที่ถ่ายเอง 1 ภาพ เป็นไฟล์ .jpg หรือ .png คัดลอกไปไว้ในโฟลเดอร์ D:\cv\unit2 แล้วตั้งชื่อเป็นภาษาอังกฤษ เช่น my_photo.jpg ภาพจาก iPhone ที่เป็น .heic ต้องแปลงเป็น .jpg ก่อน
  2. สร้างไฟล์โปรแกรมเปิดโฟลเดอร์ D:\cv\unit2 ใน VS Code สร้างไฟล์ my_image.py แล้วคัดลอกโค้ดตั้งต้นด้านล่างไปวาง จากนั้นกด Ctrl+S
  3. เขียนโค้ดและทดสอบเขียนต่อตรงบรรทัด เขียนต่อที่นี่ ให้ครบ 5 ข้อตามตาราง แล้วกด Run โดยใช้ fruits.png ก่อน ถ้ายังไม่มีไฟล์นี้ ให้ดาวน์โหลดจากใบความรู้ 2.1
  4. เปลี่ยนเป็นภาพของตนเองเมื่อผลตรงกับค่าทดสอบแล้ว แก้บรรทัด cv2.imread("fruits.png") เป็นชื่อไฟล์ภาพของตนเอง เช่น cv2.imread("my_photo.jpg") กด Ctrl+S แล้วกด Run อีกครั้ง
  5. เก็บผลงานจับภาพหน้าจอ Terminal ด้วย Win+Shift+S ตรวจว่ามี my_gray.png ใน Explorer แล้วนำค่าจาก Terminal มากรอกในส่วนบันทึกผลด้านล่าง

1อ่านภาพ และตรวจกรณีเปิดภาพไม่ได้ถ้าชื่อไฟล์ผิด โปรแกรมแจ้งข้อความและหยุดทำงาน
2พิมพ์ความกว้าง ความสูง จำนวนช่องสี และจำนวนพิกเซลค่าทั้ง 4 แสดงใน Terminal
3พิมพ์ค่า B, G, R ของพิกเซลกึ่งกลางภาพค่าทั้ง 3 อยู่ในช่วง 0 ถึง 255

1อ่านภาพ

เปลี่ยน "fruits.png" เป็นชื่อไฟล์ภาพของตนเอง ตั้งชื่อเป็นภาษาอังกฤษ และเก็บไว้ใน D:\cv\unit2

2พิมพ์ขนาดภาพ

ใช้ print() แสดงตัวแปร width, height และ channels จำนวนพิกเซลคือ กว้าง × สูง

3อ่านพิกเซลกึ่งกลาง

แถวกลางคือ height // 2 คอลัมน์กลางคือ width // 2 และต้องใส่แถวก่อนคอลัมน์

4แสดงภาพ 2 หน้าต่าง

ใช้ cv2.imshow 2 ครั้ง ตามด้วย cv2.waitKey(0) และ cv2.destroyAllWindows()

5บันทึกภาพเทา

ใช้ cv2.imwrite บันทึกตัวแปร gray แล้วตรวจว่าไฟล์ปรากฏใน Explorer

ทดสอบ: ถ้าใช้ fruits.png ต้องได้ กว้าง 1275 สูง 817 ช่องสี 3 จำนวนพิกเซล 1041675 และกึ่งกลางภาพ B = 0 G = 226 R = 252

ภาพใหญ่เกินจอ: เติม cv2.namedWindow("Color", cv2.WINDOW_NORMAL) ก่อน cv2.imshow แล้วลากปรับขนาดหน้าต่างได้
