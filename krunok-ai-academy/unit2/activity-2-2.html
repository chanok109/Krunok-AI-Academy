ใช้คำสั่งแก้พิกเซล ตัด ปรับขนาด และพลิกภาพ สร้างภาพใหม่ 3 แบบจากภาพของตนเองด้วย OpenCV

  • 10 นาทีนาทีที่ 5–15ตอนที่ 1 ทำนายผลก่อนรัน

งานเดี่ยว: ปรึกษาเพื่อนได้ แต่นักเรียนแต่ละคนต้องเขียนโปรแกรมและตอบคำถามด้วยตนเอง

ระวัง: ใช้ภาพของตนเองหรือภาพบรรยากาศ ถ้าภาพมีเพื่อนอยู่ด้วย ต้องขอความยินยอมก่อน

ตอนที่ 1 ทำนายก่อนรัน

เป้าหมายคิดให้ได้ก่อนว่าแต่ละคำสั่งจะทำอะไรกับภาพ โดยไม่ต้องรันโค้ด

ทุกข้อใช้ภาพ fruits.png ที่มี img.shape เป็น (817, 1275, 3) คือ สูง 817 กว้าง 1275 ช่องสี 3 ตอบแล้วระบบจะบอกทันทีว่าถูกหรือยัง ถ้ายังไม่ถูกให้อ่านคำใบ้แล้วลองใหม่

1crop = img[100:300, 500:900]

ภาพ crop มี shape เป็นเท่าใด

.shape = (, , 3)

2small = cv2.resize(img, (300, 500))

ภาพ small มี shape เป็นเท่าใด

.shape = (, , 3)

3img[0:100, 0:200] = [255, 0, 0]

4flip0 = cv2.flip(img, 0)

ตอนที่ 2 โปรแกรมนักแต่งภาพ

เป้าหมายเขียนโปรแกรมที่ใส่กรอบสีรอบภาพของตนเอง ตัดส่วนกลาง ปรับขนาดให้กว้าง 400 พิกเซลโดยภาพไม่ยืด แล้วพลิกแบบกระจกเงา บันทึกเป็นไฟล์ใหม่ 3 ไฟล์

  1. เตรียมภาพใช้ภาพที่ถ่ายเองจากกิจกรรมที่ 2.1 หรือถ่ายใหม่ 1 ภาพ เก็บไว้ในโฟลเดอร์ D:\cv\unit2 พร้อมไฟล์ fruits.png ถ้ายังไม่มี fruits.png ให้ดาวน์โหลดจากใบความรู้ 2.1
  2. สร้างไฟล์โปรแกรมใน VS Code สร้างไฟล์ my_edit.py ในโฟลเดอร์ D:\cv\unit2 คัดลอกโค้ดตั้งต้นด้านล่างไปวาง แล้วกด Ctrl+S
  3. เขียนโค้ดและทดสอบเขียนต่อตรงบรรทัด เขียนต่อที่นี่ ให้ครบ 5 ข้อตามตาราง แล้วกด Run กับ fruits.png ก่อน ผลใน Terminal ต้องตรงกับค่าทดสอบ
  4. เปลี่ยนเป็นภาพของตนเองและเลือกสีกรอบแก้ชื่อไฟล์ใน cv2.imread เป็นภาพของตนเอง และเปลี่ยนสีกรอบจาก [0, 0, 255] เป็นสีที่ชอบ (เรียง B, G, R) กด Ctrl+S แล้ว Run อีกครั้ง
  5. เก็บผลงานจับภาพหน้าจอ Terminal ด้วย Win+Shift+S เปิดไฟล์ภาพทั้ง 3 ไฟล์ใน Explorer ดูว่าถูกต้อง แล้วนำค่าจาก Terminal มากรอกในส่วนบันทึกผลด้านล่าง
my_edit.pyโค้ดตั้งต้น คัดลอกไปวางในไฟล์
import cv2

if img is None:
    print("เปิดภาพไม่ได้ ตรวจชื่อไฟล์และโฟลเดอร์")
    raise SystemExit

print("ภาพเดิม:", img.shape)

frame = img.copy()
frame[0:10, :] = [0, 0, 255]      # ขอบบน สีแดง

# เขียนต่อที่นี่ ตั้งชื่อตัวแปรว่า crop

# ข้อ 4 ปรับขนาดภาพที่ตัด ให้กว้าง 400 พิกเซล โดยรักษาสัดส่วน
# เขียนต่อที่นี่ ตั้งชื่อตัวแปรว่า small

สิ่งที่โปรแกรมต้องทำ

ข้อต้องทำอะไรผลที่ต้องเห็น
1อ่านภาพ และตรวจกรณีเปิดภาพไม่ได้ถ้าชื่อไฟล์ผิด โปรแกรมแจ้งข้อความและหยุดทำงาน
2ใส่กรอบสีหนา 10 พิกเซลครบทั้ง 4 ด้านบนสำเนาของภาพmy_frame.png มีกรอบรอบภาพ ภาพเดิมไม่เปลี่ยน
3ตัดส่วนกลางของภาพ ครึ่งหนึ่งของความสูงและความกว้างภาพที่ตัดสูงและกว้างประมาณครึ่งหนึ่งของภาพเดิม
4ปรับขนาดภาพที่ตัดให้กว้าง 400 พิกเซล โดยรักษาสัดส่วนความกว้าง 400 และภาพไม่ยืดหรือบีบ
5พลิกภาพซ้าย-ขวา แสดงภาพ และบันทึก 3 ไฟล์มี my_frame.png my_crop.png my_mirror.png ใน Explorer

คำใบ้ทีละข้อ

คลิกเปิดเมื่อติดขัด ลองคิดเองก่อน

1อ่านภาพ

เปลี่ยน "fruits.png" เป็นชื่อไฟล์ภาพของตนเอง เก็บไว้ใน D:\cv\unit2 ตัวแปร h คือความสูง w คือความกว้าง

2ใส่กรอบสี

ขอบล่างคือ 10 แถวสุดท้าย เริ่มที่แถว h-10 ขอบซ้ายและขอบขวาใช้ : ในตำแหน่งแถวเพื่อเลือกทุกแถว แล้วเลือกเฉพาะคอลัมน์ที่ต้องการ

3ตัดส่วนกลาง

ส่วนกลางเริ่มที่ 1 ใน 4 และจบที่ 3 ใน 4 ของภาพ ใช้ h // 4 และ 3 * h // 4 สำหรับแถว แล้วทำแบบเดียวกันกับ w สำหรับคอลัมน์

4ปรับขนาดรักษาสัดส่วน

ความสูงใหม่ = ความสูงของ crop × 400 ÷ ความกว้างของ crop ครอบด้วย int() ให้เป็นจำนวนเต็ม แล้วใส่ใน cv2.resize เป็น (กว้าง, สูง)

5พลิกภาพและบันทึก

ใช้ cv2.flip(small, 1) แสดงด้วย cv2.imshow แล้ว cv2.waitKey(0) และบันทึกด้วย cv2.imwrite ให้ครบ 3 ไฟล์
