## วิธีอัปโหลดขึ้นเซิร์ฟเวอร์โรงเรียน

1. แตกไฟล์ zip
2. อัปโหลดทั้งโฟลเดอร์ `krunok-ai-academy` ไปไว้ในพื้นที่เว็บ เช่น `public_html/` หรือ `htdocs/` (ผ่าน FTP, cPanel File Manager หรือ DirectAdmin)
3. ให้คงโครงสร้างโฟลเดอร์ไว้เหมือนเดิม ถ้าเคยอัปชุดก่อนหน้า ให้ลบโฟลเดอร์ `unit5` เดิมออก (ย้ายมาเป็น `unit4` แล้ว)
4. เปิดเว็บที่ `https://<โดเมนโรงเรียน>/krunok-ai-academy/`

เว็บนี้เป็นไฟล์ HTML ล้วน ไม่ต้องใช้ PHP หรือฐานข้อมูล ใช้ได้กับเซิร์ฟเวอร์ทุกแบบ

## การเข้าสู่ระบบ

- ชื่อผู้ใช้และรหัสผ่านคือรหัสนักเรียน (ตัวเลข 4–10 หลัก)
- ตอนนี้ตรวจในหน้าเว็บเท่านั้น (รหัสผ่านต้องตรงกับชื่อผู้ใช้) ยังไม่ตรวจกับรายชื่อนักเรียนจริง และยังไม่บันทึกคะแนนลงเซิร์ฟเวอร์
- ความคืบหน้า ดาว คำตอบที่พิมพ์ และคะแนนแบบทดสอบ เก็บไว้ในเบราว์เซอร์ของนักเรียนแต่ละเครื่อง
- แบบทดสอบ AI Quest ให้นักเรียนถ่ายภาพหน้าจอใบสรุปผลส่งครู

## เปิดหัวข้อหน่วยที่ 2 ทีละสัปดาห์

ใบความรู้หน่วยที่ 2 แสดงเฉพาะหัวข้อที่เปิดไว้ และปุ่ม "เมนูบทเรียน" พากลับหน้าแรก (`index.html`)
ถ้าจะเปิดหัวข้อเพิ่ม ให้แก้บรรทัด `open:['t21','t22','t23']` ใกล้บนสุดของไฟล์ `unit2/index.html`
(t21 t22 = 2.1, t23 = 2.2, t24 = 2.3, t25 = 2.4, t26 = 2.5, mission sum = ภารกิจและสรุป)

## หมายเหตุ

- กิจกรรมที่ 1.1 Research Sprint และ 1.2 Garden Designer ดาวน์โหลด PDF ได้จากเบราว์เซอร์โดยตรง (ใช้ html2canvas และ jsPDF จาก cdnjs ต้องมีอินเทอร์เน็ต)
- ปุ่มส่งงาน Google Classroom ใน Mission Board ยังไม่มีลิงก์ ครูใส่ได้ที่บรรทัด `GOOGLE_CLASSROOM_ASSIGNMENT_URL` ในไฟล์ `activities/1-1-mission-board.html`
- สไลด์ Generative AI เบื้องต้น และใบงานและเกณฑ์ประเมินหน่วยที่ 4 ฉบับเดิม (เอกสาร Claude) ไม่ได้อยู่ในชุดนี้ ดาวน์โหลดจากเมนู Export ของหน้านั้นเป็น PDF หรือ PowerPoint แล้วอัปเพิ่มได้
